# Логотип Norocel

Источник — `logo.png` в корне репозитория. `npm run brand` в `frontend` генерирует SVG-логотипы для светлой/тёмной темы, знак N, анимированный лоадер, SVG/ICO-фавиконы, Apple Touch Icon и обычные/maskable PWA-иконки. Генерация также выполняется перед `npm run dev` и `npm run build`.

Надпись переводится в векторные контуры из исходного изображения. N, монетка и передняя стенка кармашка — отдельные SVG-слои; монетка падает, слегка отскакивает и скрывается за кармашком. При `prefers-reduced-motion: reduce` показывается статичный знак. Текст загрузки доступен скринридерам на выбранном языке.

Файлы синхронизируются в `backend/public/icons`, `frontend/public/icons` и `public-site/public/icons`. После сборки `node scripts/public-site-assets.mjs` синхронизирует CSS и OpenGraph-изображение публичного сайта в общий document root. Все ресурсы лоадера и логотипа входят в офлайн-кеш PWA; изменение ресурсов обновляет версию кеша.

Проверка: production-сборка и 4 frontend unit-теста, 5 тестов публичного сайта (294 assertions), 4 браузерных сценария кабинета (390/1440, светлая/тёмная темы). Локальная проверка брендинга подтвердила страницы сайта на 360/390/430/768/1024/1440, начальный лоадер до запуска React, положение монетки на этапах анимации, reduced motion и загрузку логотипа/иконок офлайн. Предпросмотр и результаты — `.runtime/branding/loader.gif` и `.runtime/branding/checks.json`.
